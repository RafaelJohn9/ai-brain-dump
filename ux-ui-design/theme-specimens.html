Theme Specimens

Twelve concrete subjects, twelve distinct visual identities — palette, typography, and layout chosen for what each one actually is, not filled into the same template with different colors swapped in.

Companion to Color Scheme Specimens, which isolates color relationships alone. This page goes further: each tile also gets its own type pairing and a structural detail specific to its subject. Like that page, every tile is a fixed, self-contained world and doesn't respond to this page's own light/dark theme.
