Color Scheme Specimens

Twelve color-scheme strategies, each applied to the same demo card so they're directly comparable — not twelve different layouts, one layout wearing twelve different colorways.

Each specimen is a fixed, self-contained palette — it doesn't respond to this page's own light/dark theme, the same way a printed swatch doesn't change color under different light. Only this page's own chrome (this text, the nav, the borders around each tile) follows your system theme.
